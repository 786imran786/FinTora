# Public Engine API Contract

The public contract is declared in `engine/include/fintora/engine/api.hpp`.

## Value Types

- `OrderId`, `TradeId`, `Price`, `Quantity`, and `Sequence` are unsigned 64-bit integers.
- `Order` contains a deterministic ID, side, order type, quantity, and an optional price.
- LIMIT orders require a price; MARKET orders do not carry a price.
- `Trade` exposes execution price, execution quantity, both participant order IDs, and a sequence.
- `OrderView` exposes the original order, remaining quantity, and current status.
- `OrderBookSnapshot` exposes aggregate bid and ask levels, best bid, and best ask. Bids are highest-first and asks are lowest-first.

## Engine Interface

Engine implementations must implement `IMatchingEngine`:

```cpp
SubmissionResult submitOrder(const Order& order);
CancellationResult cancelOrder(OrderId orderId);
std::optional<OrderView> getOrder(OrderId orderId) const;
OrderBookSnapshot getOrderBookSnapshot() const;
```

`SubmissionResult::trades` contains the trades generated by that submission in deterministic execution order. A rejected submission returns `accepted == false`, `status == OrderStatus::Rejected`, and may provide `rejectionReason`.

`CancellationResult::cancelled` indicates whether an active order was cancelled. The result reports the remaining quantity and resulting status.

This header defines the contract only. It intentionally contains no matching algorithm or concrete engine implementation.
